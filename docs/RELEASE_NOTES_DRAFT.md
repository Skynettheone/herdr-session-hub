# Unpublished 0.1.0-rc.1 candidate — draft notes

Herdr Session Hub adds one collapsible History/Usage panel beside Files and
Changes. Browse explicit local histories, preview/search safely, organize entries
without changing originals, and inspect recorded token/cache/cost usage with
native themed graphs. Encrypted metadata file exchange is available; no native
transcript restore, original deletion or remote sync is enabled.

Windows x64 native continuation is verified for Claude Code 2.1.322, Codex
0.164.0, Pi 1.1.0, OpenCode 1.3.17 and Gemini 0.49.0 with Herdr 0.1.15.
Unknown versions, active/ambiguous sources and unsupported providers fail closed.
Gemini duplicate snapshots and bounded/partial accounting remain explicit.
Usage estimates are recorded local API-equivalent data, not subscription bills
or live account quotas. Distinct company identities are not certified.

Linux x64 and Apple Silicon macOS have experimental offline bundles, native
key-store encryption, private state, source locks and transactional installers.
All three hosted platform jobs and combined CodeQL pass. **POSIX native provider
continuation remains disabled:** real Herdr GUI/context acceptance is unavailable.
Intel macOS has no compatible wheel for the pinned encryption version.

The user requires both ports before production readiness. This candidate remains
`0.1.0-rc.1 / releaseReady=false`; these notes are not an announcement or permission
to publish. No production configuration was an installation target. Check current
artifact receipts in RELEASE_REPORT.md and scope in PORT_ACCEPTANCE.md before any
later publication decision. Obtain explicit approval before installing into the
production app home, creating a release/tag or listing the mod in the gallery.
