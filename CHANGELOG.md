# Changelog

## 0.1.0-dev — 2026-11-12

- Added a native GPUI history panel with explicit profiles, filters, project
  grouping, search, previews, archive, aliases and reversible Hub removal.
- Added independent read-only Claude, Codex (including bounded zstd), Pi and
  quiescent OpenCode SQLite adapters, plus incremental/cancellable refresh.
- Added opt-in local FTS5, DPAPI state, atomic backups/recovery, version guards
  and argument-vector native resume requests with unverified outcomes.
- Added encrypted offline metadata bundles, dry-run import, preserved conflicts
  and explicit local annotation linking.
- Added Windows synthetic regression tests, native GUI smoke evidence,
  offline installation, uninstall and development packaging with checksums.
- Kept original deletion, native migration and remote sync unavailable.
- Production release remains blocked on native context-continuation checks,
  precise active ownership, update validation and independent review.
